# 浏览器双语阅读设计

版本 v0.4.0 · 2026-10-08。

参考沉浸式翻译的双语网页、划词浮层和按需段落翻译形式，使用 WordMate 自己的实现与样式，不复制其品牌或代码。参考：[官方介绍](https://immersivetranslate.com/zh-Hans/)、[划词形式](https://immersivetranslate.com/zh-TW/highlight)、[悬停说明](https://immersivetranslate.com/zh-Hans/docs/features/hover/)。

## 本版流程

1. 扩展按钮 / 网页右键：整页双语翻译；译文紧跟原段落，使用正文相近字体和轻量颜色，保留链接、强调、原文。
2. 选中单词 / 段落：右键翻译，结果在选区附近浮层展示；激活当前页后，选区旁还出现小型翻译按钮，点击才请求模型。
3. 鼠标停在段落上按 Shift：仅翻译该段，译文出现在原文后；只在用户激活当前页后生效。
4. 停止：不再启动新请求，迟到响应不插入页面；已有译文保留。恢复原文：只移除扩展添加的译文，保留网站动态更新。
5. 页面失败：显示原因和重试未完成内容；连接失败停止队列。选词失败：保留原选区文本，浮层可重试。

## 验收

英文整页可见已加载段落显示中文译文；目标语言也可选英文。内联链接和强调合并成完整段落翻译。重复操作不重复翻译未变化内容；动态变化段落和新内容可再次翻译。

划词结果留在浏览器，不唤起查词窗；完整单词释义、音标、例句可展示。翻译浮层靠近选区且限制在屏幕内。选词是否入本遵守桌面设置；整页和按需段落不入本。

隐藏内容、表单输入、可编辑文本、代码不发送；浏览器禁注入页面、图片文字、未加载内容和跨域嵌入页面不承诺支持。激活权限按当前页授予，本版不自动全站常驻。

## 阅读与入本细则

双语逐段上下对照；中文覆盖模式直接修改保存的源文字节点，隐藏双语第二行。原文片段编号与译文编号匹配，模型返回数组或编号对象后统一归一化；不使用 innerHTML。两种模式可即时切换，停止不撤销已有译文，恢复原文保留网站动态变化。

控制面板在角落，成功后收起；不遮挡阅读主体。译文不降低透明度、不加独立彩色大卡片；原生段落中用轻量分隔线区分原文与译文。

Thinking 在扩展弹窗可即时保存到桌面配置，默认关闭；桌面设置也可关闭并选择服务端适配字段。单词浮层提供主动入本和已收录状态，自动入本遵守桌面设置。
