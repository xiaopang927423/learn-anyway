# 联网词库、个人记忆与查词恢复

适用：桌面版 0.6.2、输入法 0.6.5 / build 6050。

用户需要解决：领域词库没有更新入口、部分文件不可用、常用人名需要反复翻找，以及查词时出现“AI 返回的不是有效 JSON”。

- 输入法“设置 → 词库”提供检查更新、更新已启用词库、单本下载/更新/修复。显示已安装版本、最新版本、条数、下载大小、许可证和进度。
- 首批支持 Qingjian 官方 11 本中文领域词库与可选通用扩展词库。基础词库、英语释义、模型和用户自行导入文件不由此服务替换。通用扩展部分词形和读音未经人工审核，默认不自动安装。
- 默认每天自动检查并更新已启用的领域词库；用户可关闭自动更新，仍可手动操作。没有更新时不重复下载，不降级到旧版本。
- 下载失败、校验失败、离线时保留原文件；在线文件损坏时可回退到随包词库。只有安装成功的手动下载才自动启用。下载成功后等待当前输入结束再装配，正在翻页选词时不换候选。
- 个人记忆默认启用，可在词库页直接开关。显示已记住的词/短语数量；人名、组合短语、选词次数和近期习惯保存在本机。学习关闭或私密输入时不记录，词库联网只下载公开数据，不发送输入内容。
- 最近 16 次同拼音选择参与排序，旧的高频记录不再长期压制新习惯；累计计数保留供撤销与诊断。重启、更新词库不清空个人记录。
- 桌面查词要求 JSON 输出；兼容不支持 response_format 的接口。响应空白、截断或格式不正确时最多重新生成一次，共用 45 秒超时；鉴权失败和明确拒绝不重试，不把模型推理内容当作译文。
