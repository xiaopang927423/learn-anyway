# v0.6.3 句子翻译与英文语法检查

桌面提供“句子翻译与语法检查”入口：中文输出自然英文；英文输出中文译文，并标出语法、拼写、标点或表达问题。明确错误和可选表达建议分开标记，保留原句、逐项说明和修正后的英文。正确表达不强制改写。

输入内容变化时旧结果失效，用户可复制修正，或用修正后的句子继续检查。检查结果本身不加入生词本，仍保留用户主动点词入本。

英文输入法在单词上屏、空格或标点之后暂停约 1.2 秒时，检查光标前当前英文句子。有问题时显示浮动解释；只在用户点击“采用修正”且原句、光标和会话仍一致时替换。继续输入、切换焦点或模式使旧结果失效。宿主不支持读回文本时不自动检查。

设置提供“英文输入时检查语法与表达”。检查沿用用户配置的模型接口；密码、安全输入、隐私模式及排除的应用不发送文本。输入法检查不写入学习库或句子缓存。桌面单次上限 4000 字符，输入法当前句子上限 1000 字符，网络失败不阻塞正常输入。

数字在英文模式中为正文；Tab 或鼠标接受补全。中文组词时数字选择当前页候选，没有组词时数字为正文。支持系统不同输入回调；单击 Shift 切换中英，同时保留 Ctrl+Shift+E。

实际宿主兼容性单独验收，不以模拟客户端通过代替 Chrome 的真实键盘结果。
