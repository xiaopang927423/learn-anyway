## WordMate 新增能力如何叠加

- 默认只改活动片段：we want to eat [早饭] → we want to eat breakfast。基础中文候选仍可照常确认；英文辅助独立操作区，不抢基础 1–9 编号和固定短语位置。
- 支持句首、句中、句尾中文占位和明确选区；[早饭]→breakfast，[吃早饭]→have breakfast，不改已有 eat，避免 eat have breakfast。
- 源候选含义改变使旧译文失效；云结果不重排已高亮基础候选，不自动上屏。整句操作必须另行确认范围。
- 实际采用英文后写现有英语词本，记录中文意思和必要语境。预览、取消、普通英文、emoji 不自动收录；已有词去重，已掌握状态保持。
- 基础英语注记快捷键采用也遵守写入成功、入本开关和提交去重规则，不形成第二条绕过规则的学习路径。无可靠提交证据时只能手动加入。

## 设置与交付管理

英语输入辅助单独开启，首次云请求说明发送范围；关闭不影响基础输入。学习语言只有英语 / 关闭注记，翻译输出仍可中英选择。参考日语 / 西语配置迁移提示回退英语，不改现有词本。

快捷键展示作用状态、冲突及恢复默认；非组句时交给应用。基础 Esc 清空组合串；辅助 Esc 仅关闭译文回到基础组句。切换输入方案保留或明确处理编辑文字，同时使旧响应失效。

配置、词库、输入习惯和词本分别备份；清空习惯不能清空词本。词库、模型、OpenCC、英文词表、注记数据逐项记录来源、版本、许可、体积、缺失行为；参考数量不是未核实的打包承诺。

G0 建立每项“参考文档 → macOS 代码入口 → 适配方案 → 验收证据”台账，区分已有实现、文档待补和平台专属。G1 完成适用 macOS 基础项，G2/G3 增加片段翻译和学习。未通过项标明未完成，不能因只学英语而删去输入方案。代码及资产许可方案在复制 / 链接前确定；不复用参考品牌，不执行参考安装脚本。
