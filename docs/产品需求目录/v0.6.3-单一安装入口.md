# v0.6.3 单一安装入口

用户反馈启动器出现三个 WordMate、两个 WordMateInput，无法判断哪个是当前版本。

- 桌面应用保留已有的 /Applications 安装位置；首次安装使用 ~/Applications。升级成功后只留一个桌面应用。
- 原生输入法继续使用 ~/Library/Input Methods/WordMateInput.app，身份和选中的输入源保持不变。
- 构建产物不进入应用搜索；回滚备份采用 ZIP，不留下可启动的应用副本。
- 不清空废纸篓，不删除学习数据、模型设置或其他软件。旧项目仅清理已确认的生成应用，不修改源码。
- 失败时保留原应用或已验证的恢复备份；不可写的现有安装在覆盖前报告错误。

验收见测试目录的 2026-11-19 重复应用清理记录。
