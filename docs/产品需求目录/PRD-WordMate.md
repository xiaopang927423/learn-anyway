# WordMate 产品需求文档

版本：v0.4.1 · 更新：2026-10-08 · 平台：macOS + Chrome / Edge / Chromium 扩展

## 目标与范围

在阅读英文时，选中文字即可翻译；结果可沉淀到本地生词本，并支持复习和默写。支持单词、固定短语、中文表达和完整句子。云端模型请求时间取决于服务端，缓存命中应即时展示；不承诺所有网络请求 1 秒完成。

## 翻译入口

1. 菜单栏 W 或 ⌥Space：打开或收起查词窗，输入并回车查询。
2. macOS 支持文本服务的应用：选中文字 → 右键 → 服务 → 用 WordMate 翻译。必须将打包后的 .app 安装至 ~/Applications 或 /Applications 并注册服务；部分应用不会提供服务菜单，不能承诺任意软件均支持。
3. Chrome / Edge / Chromium：安装 MV3 扩展及本机 Native Messaging 连接程序后，选中文字 → 右键 → 用 WordMate 翻译。连接程序通过 wordmate:// 协议将文本送到桌面应用；扩展不持有 API Key。
4. ⌥D：模拟复制读取完整选区，支持中英文句子；需辅助功能权限。复制失败或没有选区时提示，不使用原剪贴板旧文本。优先通过辅助功能直接读取选区；复制备用路径保存全部剪贴板项目，检测额外并发变化后保留最新剪贴板。

选区最大 12000 字符。浏览器扩展采用固定 ID；设置可一键安装本机连接，浏览器仍需加载扩展文件夹；Safari 暂使用系统服务，未提供 Safari 扩展。

## 查询与模型

- 默认 DashScope Qwen；支持自定义 OpenAI 兼容 chat/completions 接口。
- Diffu：模型 diffu；package 3 的 config/models.json 提供地址、模型和密钥。设置页可导入，或选择 Diffu 预设再填密钥。密钥不得写入 PRD、源代码或输出日志。
- Diffu temperature=0，不使用 developer role、reasoning_effort 或 strict schema；允许输出带 think 标签，解析前移除。
- 查询与连接测试 45 秒超时；失败给出错误原因；英文单词可降级到 ECDICT，词典需另行安装。
- 缓存按输入原文、上下文、接口地址、模型隔离，避免换语境或换模型返回旧释义。
- 界面仅展示最后一次查询响应，异常后解除加载状态。

## 结果与生词本

- 英文单词 / 固定短语：音标、释义、例句、搭配、辨析、词形变化、记忆法、联想词。
- 中文短语：英文表达、替代表达、例句和用法。
- 完整句子：中英互译、说明、英文一侧可点词入本。
- 自动入本开关适用于所有查询入口；中文表达和句子不整体入本。用户主动点词入本可独立收录。
- 生词本：搜索、展开详情、删除、已掌握 / 重新学习。可编辑释义、上下文、例句和记忆法；删除后可撤销，保留原学习排程。
- 入本后更新托盘待复习数。所有学习数据存在本地 SQLite；输入及上下文会发送到所配置的模型服务。

## 复习与默写

- 复习：到期旧词优先，其后所有未学新词；无每日新词配额。队列按查询次数和距离上次学习时间排序。
- 空格翻面；1 不认识 / 2 模糊 / 3 认识。失败的评分保留当前卡片以便重试。
- 不认识：10 分钟后到期；模糊：至少 0.75 天；认识：首次 1 天，随后 ×2.2，最多 365 天。连续认识至少 3 次且间隔至少 21 天建议已掌握。
- 默写：中文释义及例句挖空、一次重试、字符 diff、错词重考、结算报告。
- 常规默写排除当天已经复习 / 默写的词；自由练习允许学习中词再次练习。
- 默写计分前检查当天学习记录，已计分词不重复影响排程。日志与计分在同一事务内提交；提交标识支持幂等重试，卡片版本阻止过期窗口重复评分。复习仅接受新词或实际到期卡片，保留 10 分钟后重学。自由练习 / 错词重考不影响排程。

## 窗口与设置

所有辅助页均有明确返回按钮，返回来源页面；Esc 同样返回。窗口返回或收起时保留查词结果和学习进度。设置页返回前处理未保存修改，可保存并返回、放弃修改或继续编辑。保存和测试按钮固定可见。查词支持多行输入、Shift+回车换行、清空和复制译文。

查词窗置顶；Esc 关闭、再次点击托盘收起；不失焦自动隐藏。打开其他页面时收起查词窗。设置含地址、Key、模型、连接测试、Diffu 导入、提醒、自动入本、默写数量 / 联动、CSV 导出。浏览器安装流程见 README。

## 验收标准

- 支持服务的应用及浏览器选中整句，收到完整选区并翻译。
- 关闭自动入本后，所有划词入口均不会自动收录；主动点击收录仍可用。
- 同输入不同上下文 / 模型独立缓存。
- 网络错误、异常 JSON、评分失败后界面可继续操作。
- Diffu 连接测试及真实结构化翻译请求成功。
- 使用隔离数据库运行冒烟测试，不写测试词到真实学习库。

## 回归验证与平台限制

已通过单元与真实 Electron/SQLite 集成回归：跨窗口双向防重复计分、事务回滚、幂等重试、自由练习、删除撤销、编辑、即时队列同步、设置返回和未保存修改处理、返回保留查词结果、异步收录竞态、清空阻止迟到结果。

系统服务仅适用于提供文本服务的应用；浏览器点击验收需要可用的浏览器控制权限。无权限时不能将程序化验证描述为真实浏览器菜单点击通过。Safari 暂通过系统服务，没有独立 Safari 扩展。

## v0.3.0 浏览器内翻译

- 整页翻译：扩展图标或网页右键启动，按可见已加载段落保留原文插入译文，原链接和强调样式不变。
- 局部翻译：选中单词或段落，右键或扩展按钮启动；网页浮层显示词典 / 译文、例句、错误与重试，不弹出桌面查词窗。
- 页面翻译可选中文 / 英文、停止、恢复原文、重试失败和翻译新加载内容。原文不被替换，因此恢复操作只删除本扩展的译文。
- activeTab + scripting 仅在用户操作后注入当前页面，不自动扫描全部网页。隐藏文字、代码、表单和可编辑区排除；图片文字 / 未加载内容 / 浏览器禁止注入的页面不属于此版范围。
- 后端通过 0600 权限 Unix socket 给 Native Messaging 返回结果；模型密钥留在桌面。按段落 + 目标语言 + 模型缓存；整页内容不入生词本，选词遵守自动入本设置。
- 新版扩展新增 activeTab / scripting 权限，已安装版本需要浏览器重新加载。受权限限制，测试采用真实 Chromium DOM + 模拟 Chrome 消息接口，不能声明真实 Chrome 菜单已点击验收。

交互参考与验收细则见 [浏览器双语阅读设计](浏览器双语阅读设计.md)。当前页激活后支持划词小按钮和 Shift 按需段落翻译；划词浮层靠近选区，整页译文采用轻量正文样式。

## v0.4.0 阅读模式、Thinking 与划词入本

- 双语对照：每个原生段落内形成一段原文 / 一段译文的 1:1 对照；使用原页面字体和完整对比度，避免独立译文网格项。完成后控制面板收起到角落。
- 仅中文 / 仅译文：直接替换原文字节点，不叠加第二行；原链接、强调和原生布局保持。切换回双语或恢复原文可恢复保存的源文字，不覆盖网站后来更新的文本。
- 阅读模式在扩展弹窗和网页控制条中可切换，不重复请求模型。按带编号的原文片段映射译文，避免中文覆盖时破坏链接和强调结构；缺失片段时报错并保留原文。
- Thinking 默认关闭。浏览器弹窗与桌面设置共用持久化开关；字典、整页、连接测试都使用该开关。Diffu / Qwen 采用 chat_template_kwargs.enable_thinking，DashScope 用顶层 enable_thinking；其他接口可选择适配字段或自行控制。
- Thinking 及适配字段参与缓存键。真实 Diffu 关闭测试 reasoning_tokens=0，开启对照测试 reasoning_tokens=365；关闭不是只隐藏思考内容。
- 划词结果显示「加入生词本」；自动入本已启用时自动收录并显示「已收录」。手动收录保留句子上下文，同词不重复入库；自动入本关闭时仍可主动加入。

## v0.4.1 正文识别与仓库页面布局

整页入口调整为「翻译页面正文」。优先文章、README / markdown 文档；保留导航、操作控件、文件浏览器、仓库名称、提交标识与日期。双语只应用到可阅读语义段落，不对任意 div / a / button 追加第二行，不扩展 flex / grid / nowrap 紧凑控件。无文章容器时使用 main 内语义段落作为回退。

路径、提交哈希和 camelCase 技术名称在正文内保留。被跳过的文字仍可主动划词翻译。该策略也用于仅译文模式，避免改变应用界面的操作语义。
