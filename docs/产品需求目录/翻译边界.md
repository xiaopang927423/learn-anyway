# 当前翻译边界

版本 v0.4.3 · 2026-10-08。此文档为当前覆盖合同，替代历史版本中“只翻译 article/p”或“整体跳过侧栏”的规则。

## 核心原则

用户启动页面翻译后，对当前已加载、可见、可阅读的 DOM 文字进行翻译。内容是否位于 div/span、aside、header 或 flex/grid 中，不作为跳过理由。优先选择完整段落和信息单元；展示方式按所在布局选择，避免将整行控件或父级网格改成段落。

## 覆盖矩阵

| 内容 | 翻译 | 展示 / 保护 |
| --- | --- | --- |
| 文章段落、标题、列表说明 | 是 | 一段原文 / 一段译文，或原位置仅译文 |
| 搜索结果标题和摘要 | 是 | 内联强调合并成完整语境；摘要截断不隐藏译文 |
| 站内链接标题和说明 | 是 | 保留链接目标；说明仍在原信息单元 |
| 侧栏知识面板、企业说明 | 是 | 不因 aside 或另有文章正文被跳过 |
| 普通知识 / 业务表格的字段与值 | 是 | 同一格内配对；网格不新增父级单元 |
| 社交帖子、引用帖 | 是 | 正文可译，可点击外框不排除正文；作者等元数据保留 |
| 新加载、展开、虚拟列表更新文字 | 是 | 启动翻译后自动补译；停止 / 恢复后关闭 |
| 导航、标签页、菜单、操作按钮 | 否 | 保留操作界面；其中独立长说明卡片不当作按钮标签 |
| 输入值、可编辑草稿、隐藏文本 | 否 | 不读取到翻译请求 |
| 代码、脚本、SVG/canvas 内文字 | 否 | 不属于此版本的 DOM 阅读范围 |
| 文件浏览器、路径、URL、哈希、技术标识 | 否 | 保留原文，主动划词仍可用 |
| 账号 / 仓库身份、仓库可见性徽章 | 否 | 保留标识，不将姓名 / 路径当普通词语 |
| 图片文字、未加载内容、关闭 shadow root、禁注入页面 | 本版不支持 | 不声明全站 OCR / 跨域 iframe / PDF 覆盖 |

实体名称和自然语言日期在说明正文中可以翻译；技术路径、账号、原始 URL 等需要保持原样。不是把一切专有名词都作为“禁止翻译”处理。

## 展示和恢复

双语模式的译文放在内容所在的叶级单元中，避免文件行和父网格增加单元。内容单元需要换行或解除截断时，仅修改该单元并记录原样式。仅译文模式改写保存的源文字节点，保留链接 / 强调节点。恢复只回退仍由扩展写入的文字和样式，不覆盖网站后续更新。

## 验收方式

文章、仓库、社交、搜索和知识面板必须一起回归。覆盖检查以具体可读文本是否进入请求、是否有配对译文、控件是否保留为准；成功段落数不等于整页覆盖率。真实浏览器点击验收和模拟接口的 Chromium DOM 验证分别记录。
