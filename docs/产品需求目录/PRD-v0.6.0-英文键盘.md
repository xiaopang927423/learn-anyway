# WordMate 0.6.0 英文键盘 PRD

日期：2026-10-12。版本代号 0.6.0，实验性 macOS 输入法；不代表正式稳定发行。用户确认采用英文模式：直接输入英文、Space 正常空格、支持单词补全与中英切换。

## 范围

新增独立英文键盘流程，沿用现有英文词库和个人词频学习。桌面查词应用和浏览器扩展本轮不升级版本；原有 0.5.0 中文/混输、整句翻译、词本接口保持兼容。英文键盘以逐词输入为主，不把整句话强制留在黑框。

## 模式与按键

| 场景 | 行为 |
| --- | --- |
| 单击左/右 Shift | 按下后松开切换；Shift 加字母/组合键、长按、双 Shift、失焦不切换。设置中可关闭 |
| Ctrl+Shift+E | 备用切换中英文；可在输入法快捷键设置修改，修改后持久保存 |
| Caps Lock | 保留既有切换入口；物理状态变化覆盖软件模式选择 |
| 切换时已有组合文本 | 先保留当前原始输入，再切换；不自动翻译、不删除原文 |
| 英文 Space | 一次写入原词和一个半角空格，候选高亮不会自动改写原词 |
| 连续 Space | 每次增加一个空格，不要求两次确认 |
| 英文 Tab，有待输入词 | 采用当前高亮补全；上下键可先选补全，鼠标选词也可采用 |
| 英文 Tab，无待输入词 | 交给宿主切换焦点；Shift+Tab 同样保留焦点导航 |
| 字母、大小写、数字 | 保留实际字符，1–9 不作为选词；支持 foo123、Diffu 等自定义标识符 |
| 词内撇号、下划线、连字符 | 可继续输入 don't、foo_bar、well-known |
| 标点、粘贴、其他文字 | 先保留待输入原词，再交给宿主处理；英文半角标点不转中文标点 |
| Backspace | 先编辑待输入词；为空时由宿主删除 |
| 左右、Home/End、删除前文 | 先保留待输入词，再由宿主编辑已输入的句子 |
| Esc | 关闭补全并保留原词，不清空已输入句子 |
| Enter，有待输入词 | 只确认原词，消耗当前按键，避免同次发送；下一次 Enter 为宿主行为 |
| 翻译预览中的 Enter | 消耗按键，不采用、不发送 |
| Ctrl+Option+T | 保留主动翻译当前组合或应用选区的入口 |
| 中文 Space / Option+Space / Tab | 沿用当前候选上屏 / 英文采用 / 草稿空格及自定义设置 |

中英状态显示在菜单栏；英文黑框底部明确说明 Space 空格、Tab 补全和实际中英切换键。英文模式的普通键优先于中文确认快捷键，防止配置和旧习惯导致空格丢失。

## 补全、学习与失败边界

补全来自本地词库和既有确认学习，不自动调用模型纠正用户输入。词库未覆盖的单词保持原文可输入。关闭英文候选后仍是英文直通。IDE/终端默认直通以保留宿主补全；用户可在常规设置取消应用限制。Tab/鼠标采用词条使用现有确认学习；Space 输入原词不视为采纳模型译文，不自动新增译文学习记录。

Secure Input 与登录窗口保留系统直通，不读取敏感上下文、不触发模型。快捷键不得与已有确认、草稿空格、翻译或桌面查词键重复；冲突拒绝保存，旧配置缺字段补默认值。系统或宿主占用的快捷键无法保证收到，可改为其他组合。

## 验收

1. 输入 I want to eat breakfast，四个单词间各按一次 Space，结果含真实空格、大小写正确。
2. bre 的候选可选择 breakfast，Tab 一次采用；未选择补全时 Space 输出 bre 加空格。
3. foo123、Diffu、don't 及连续空格可输入；无词条仍有原文输入路径。
4. 已输入前文可用左右键移动并编辑，不被锁在输入法草稿里。
5. 切回中文后 nihao 一次 Space 为你好，0.5.0 中文草稿回归保持通过。
6. IDE 英文模式默认不抢宿主补全、Tab/标点/快捷键；关闭候选仍可正常打字。
7. 版本、包名、安装脚本统一为 0.6.0；升级不变更输入源身份、不覆盖个人学习数据。

自动化客户端只验证控制器分发；真实浏览器、Codex、TextEdit、IDE 物理按键与系统 Caps Lock 切换须单独人工验收。
