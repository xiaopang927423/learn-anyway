# v0.6.0 网页与 PDF 双语阅读

日期：2026-10-13。状态：本地实验版；桌面与浏览器扩展统一为 0.6.0，输入法沿用既有 0.6.0。本轮只实现方案 1（网页原位翻译）和方案 2（PDF 专用阅读器）。

## 网页

沿用整页、选区、Shift 段落翻译与动态补译；双语与仅译文即时切换。正文覆盖标题、列表、引用、表格单元格和动态内容。双语译文按原文字片段继承粗体、斜体、下划线、上下标与空白样式；原网页链接、结构、事件保持可用。双语译文中的链接文字保留视觉样式，但不创建新的可点击链接。模型片段数量不匹配时保留原文并报错。

代码、表单、编辑区、身份区、隐藏内容等继续遵循既有边界；不是任意页面元素全部翻译。

## PDF

插件新增“打开 PDF 双语阅读器”，网页/链接右键也可进入。明确以 .pdf 结尾的网络页点击整页翻译时打开阅读器。无后缀的 PDF 地址用显式入口；浏览器内置查看器不尝试直接改写。

- 打开本地文件，或粘贴 HTTP/HTTPS PDF 地址。单文件上限 100 MB。
- 网络地址填入后由用户点击打开，仅申请当前站点权限；拒绝权限、登录、网络失败时提示下载后本地打开。
- 左侧原版 PDF 页，保留图片、图表和公式视觉；右侧段落原文与译文，提供双语/仅译文切换。未翻译段落在仅译文模式仍显示原文。
- 上/下一页、页码跳转、80%–150% 缩放；当前页或单段翻译，翻页自动翻译默认关闭。
- 点击右侧段落高亮左侧原文行；点击左侧文字定位右侧段落。两侧依照对应段落定位，不承诺连续滚动比例同步。
- 左侧划词鼠标松开触发翻译，右侧选中文字点击“翻译选区”。复用词典、生词本和既有自动入本规则。
- 停止保留完成结果并禁用自动翻译；恢复原文清除阅读器所有页译文；段落失败可单独重试。
- 页码/目标语言隔离缓存，切换阅读模式和缩放不重复请求。关闭标签后阅读器缓存清除；桌面已有正文缓存仍遵循原规则。

## 边界

本版不含 OCR、视觉模型、PDF 原位置译文覆盖、翻译文件导出、Word/EPUB 解析及密码输入。需密码 PDF 先解锁。多栏与断行按几何启发式重组，复杂表格、脚注、旋转文本的语义顺序未保证；原版页面始终用于对照。网络下载不携带登录 cookie；登录保护、特殊 blob 地址和跨站重定向可能需要本地打开。

## 验收

样式片段安全渲染；原文恢复不覆盖网站更新；PDF 可选择文本、翻页、切换语言、重试、停止；旧文档/旧页的迟到结果不会写入新视图；本地文件无需站点权限；扫描页提示明确；包内含本地 PDF.js、字体与许可。验证状态见 [回归记录](../测试目录/v0.6.0-网页与PDF回归.md)。
