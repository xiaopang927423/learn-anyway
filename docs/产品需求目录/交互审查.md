# WordMate 交互审查与修复

2026-10-08 · v0.2.1

按实际任务流程审查，除功能是否存在，还检查进入、返回、取消、失败、重试和完成后的下一步。

| 场景 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 查词 → 设置 → 返回 | 设置没有返回按钮，查词窗口被隐藏后无明确出口 | 页顶「返回查词」，从生词本进入则显示「返回生词本」；返回保留输入和结果 |
| 设置修改后返回 | 修改可能丢失，是否保存不明确 | 「保存并返回 / 放弃修改并返回 / 继续编辑」；Esc 取消弹框；原生关闭收起窗口并保留草稿 |
| 长设置页保存 | 保存操作在折叠下方，需要滚动寻找 | 保存、连接测试固定在底部，错误在同一区域显示 |
| 整句查询 | 单行输入难以查看文本、无法直接复制译文 | 多行输入，Shift+回车换行，回车查询；清空按钮；复制译文 / 单词释义 |
| 查询后手动收录 | 快速查下个词，上一请求完成可能误标新卡片 | 绑定本次结果和上下文，仅更新对应卡片 |
| 清空后迟到结果 | 旧请求仍可能返回结果 | 清空增加查询序号，迟到响应不再上屏 |
| 生词管理 | 没有编辑界面；误删无恢复 | 编辑释义 / 上下文 / 例句 / 记忆法；最近删除可撤销，恢复原排程 |
| 复习 / 默写中删除或掌握词 | 无效卡片继续出现 | 主进程广播变化，学习窗口实时剔除，保留其他卡片进度 |
| 默写提交失败 | 先修改统计再保存，界面可能卡住 | 本题停留并显示「重试保存」，统计只在保存成功后更新 |
| 复习完成 → 默写 | 当天排除规则引向空队列 | 「趁热默写」打开自由练习；自由练习和错词重考不影响排程 |
| 快捷键失效 | 仅控制台日志，用户不知原因 | 系统通知及设置状态明确展示冲突，另有菜单栏 / 右键入口 |
| 浏览器初次安装 | 需要手动查找和复制 ID | 固定 ID，一键安装本机连接，打开扩展文件夹；浏览器还需加载扩展 |

自动化覆盖真实 Electron 窗口中的点击、返回、草稿处理、编辑、删除撤销、异步请求和失败重试。截图在 test-artifacts。真实 Chrome 右键菜单点击因电脑未授予 Computer Use 权限未执行，不能当作已通过。

## v0.3.0 浏览器阅读流程

原右键只弹出桌面查词窗，打断网页阅读。本版改为网页直接双语渲染，选词结果在选区附近显示；激活当前页可显示划词小按钮，Shift 按需翻译当前段落。整页译文使用正文相近的轻量样式，保留原文、链接和动态页面更新。细则见 [浏览器双语阅读设计](浏览器双语阅读设计.md)。

## v0.4.1 截图反馈

用户截图暴露文件浏览器与导航被逐节点翻译，名称误译、操作栏变高、行内布局拥挤。改为正文优先策略，保护名称 / 路径 / 日期等元数据；正文外元素通过主动划词入口处理。
