2026-10-13。本地实验版。实现范围：[需求](../产品需求目录/PRD-v0.6.0-网页与PDF双语阅读.md)、[架构](../架构目录/ADR-010-PDF阅读器与网页样式翻译.md)。

## 自动回归（模拟模型）

- `npm run lint`：语法（含 mjs）、文档链接及桌面/扩展/lockfile 版本一致性通过。
- `npm test`：33 项通过；包括 PDF 断行断词、双栏顺序、坐标、Unicode 分包、网络 URL 边界与阅读器消息路由。
- `npm run test:browser`：51 项真实 Chromium DOM 检查通过，模型与 chrome API 模拟。覆盖网页链接/强调、仅译文、动态内容、表格/网格及恢复；新增双语译文强调样式。
- `npm run test:pdf`：17 项通过；真实 PDF.js 解析合成 PDF、真实 canvas/TextLayer 与 Chromium UI，模型/站点权限/Native Messaging 模拟。覆盖双页、段落、定位、缩放、模式缓存、选区安全展示、入本、失败重试、停止、换语言、自动翻页、恢复、扫描页、换文档、拒绝权限、本地文件、390px 窗口。
- `npm run test:host`：3 项隔离 Host 回归通过。
- `npm run test:integration`：56 项桌面/IPC/socket 集成断言通过，临时数据库与模拟模型。预期模拟 IPC 失败日志属于故障用例。

本地截图与合成 PDF 位于 wordmate/test-artifacts，按规则不提交。测试 PDF 含合成职场英语，不使用私人文件。
