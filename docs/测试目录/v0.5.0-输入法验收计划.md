## P0 用例

| 编号 | 输入 / 操作 | 必须断言 |
| --- | --- | --- |
| IME-T01 | nihao，选英文 | 输出 hello；中文候选为你好；不是音译 nihao |
| IME-T02 | nihao，选中文 | 输出你好；不插入 hello；不自动发送消息 |
| IME-T03 | we want to eat + 早饭，选英文 | 只有早饭范围变为 breakfast；原英文逐字保持 |
| IME-T04 | We want to eat + 早饭 | 不生成 eat have breakfast |
| IME-T05 | We want to + 吃早饭 | 可输出 have breakfast，不机械只给 breakfast |
| IME-T06 | 尽快，选择 as soon as possible | 表达条目一条，不拆收 as / soon 等词 |
| IME-T07 | fan / xian 源解释切换 | 当前翻译与已选源意义一致，旧意义译文不能采用 |
| IME-T08 | 英文直输 / URL / 标识符 | 原字符和空格保持，不静默改写或收录 |
| IME-T09 | 编辑、退格、旧响应晚到 | 只能使用最新片段版本，旧响应不写入 |
| IME-T10 | 切应用 / 输入框 / 光标 | 旧客户端的候选不可写入新客户端或新位置 |
| IME-T11 | 空格、回车和标点 | 输入习惯明确；候选确认不顺带发送聊天消息 |
| IME-T12 | emoji、中文、组合字符 | 正确范围与光标，前后文本不损坏 |
| IME-T13 | 断网 / 未配模型 / 超时 | 本地候选和原样输入正常；用户不丢字 |
| IME-T14 | 后端退出后恢复 | 原生输入不阻塞，翻译连接能重建，无多副本混用 |
| IME-T15 | 候选预览后取消 | 无词条写入、无复习排程改变 |
| IME-T16 | 采用混输英文辅助表达 | 写入成功后收录英语词 / 表达及中文占位语义 |
| IME-T17 | 总自动入本或输入法开关关闭 | 不自动收录，主动加入仍可用 |
| IME-T18 | 词条已存在 / 已掌握 | 不重复建词、不擅自改为学习中、不双倍改变排程 |
| IME-T19 | 重复确认回调 / 学习保存失败 | 不重复写入；仅学习事件重试、commitId 幂等 |
| IME-T20 | 密码 / 私密字段 | 零云请求、零词本写入、零原始键盘日志 |
| IME-T21 | 整句操作未明确范围 | 禁止覆盖聊天框全文；明确源范围后才提供写入 |
| IME-T22 | 应用不支持可靠替换 | 原文保留、可复制译文、不能猜写入位置 |
| IME-T23 | 高频输入 / 同时网页翻译 | 本地候选时延稳定，输入请求不被网页队列长期占满 |
| IME-T24 | 安装 / 重启 / 切输入源 / 全屏 | 输入源可激活，候选定位正确，旧候选不跨会话出现 |

## 测试层次

1. 状态与分词测试：来源解释、活动片段、源意义、版本和标点边界。
2. 协议与数据测试：假模型制造慢响应 / 乱序 / 截断，验证当前结果与 commitId；临时词本验证去重、取消和保存失败。
3. 真实 IMK 测试：在 TextEdit、Notes、Chrome input / textarea / contenteditable、微信和常用编辑器实际键入，不用仅 Electron 假窗口代替。
4. 性能测试：固定机器、网络、Diffu、Thinking 状态与数据集，记录 p50 / p95；不把目标值写成实测结果。
5. 发布测试：输入源与桌面后端安装路径、升级回退、许可与数据来源清单、隐私日志检查。

当前仅完成参考阅读、需求与文档检查。未实现、不安装、不修改 qingjian，不创建 0.5.0 发布标签。
