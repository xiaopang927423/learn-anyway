# v0.5.0 输入法操作清单

2026-10-09 · 本地开发版，已更新安装。当前选字与确认分开。

1. 从系统输入法菜单选择 WordMate 输入法；如果仍出现旧界面，先切 ABC 再切回来。
2. 在普通输入框键入 nihao，空格选择「你好」。它仍在未确认组句中；可继续输入下一段拼音。回车正式输入中文，Option+回车采用下方译文，Esc 取消当前组句。
3. 输入 i、want、to、eat，每个词后按空格；英文词和空格应保留。再输入 zaocan，空格选择「早餐」，查看同一候选行下方的 breakfast，Option+回车采用。预期结果：i want to eat breakfast。已写入的英文前缀不被重写。
4. 整句中文可逐词选字并继续拼音输入，候选框持续保留；译文显示在源句下一行。Control+Option+T 明确翻译 / 重试当前组句；回车输入源句，Option+回车或点击下方译文输入翻译。
5. 已经正式输入的句子要翻译时，先选中源句，再按 Control+Option+T；这依赖应用的选区读取接口。
6. WordMate 设置中开启输入法云辅助，复用已配置模型；Thinking 可按已有开关控制。词本自动收录同时受总自动入本和输入法自动入本开关控制；仅预览不入本。
7. 输入法设置 → 通用 →「选字后保留整句，确认中文 / 译文后再输入」：关闭可恢复原版直接选词上屏。明确输入完整英文可使用 Caps Lock 英文模式。

回报问题时注明应用名、按键步骤、实际结果和截图。渲染 / 内核夹具测试不能代替实际目标应用键入验收。

## 英文空格与云辅助检查

- 默认开启组句确认时，输入 I + 空格 + want；可见内容应保留为 I want，继续输入 to eat 后空格仍在。连续空格不丢失。
- 接着输入 zaocan 并选“早餐”，原文留在待确认句中；Option+回车确认 I want to eat breakfast。回车确认原文。
- 桌面设置应出现“开启输入法云辅助”，保存后复验候选下方译文。此开关与输入法“启用云联想”分别控制翻译服务和中文补全，均使用桌面模型配置。
