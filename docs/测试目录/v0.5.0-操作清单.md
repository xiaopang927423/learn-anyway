# v0.5.0 输入法操作清单

2026-10-09 · 最新交互取代此前回车确认方案。

| 操作 | 默认按键 | 结果 |
| --- | --- | --- |
| 选中文 / 原文 | Space | 当前词正式输入，不再锁住整句 |
| 选英文 | Option+Space | 采用当前英文候选 / 译文，不发送消息 |
| 输入空格 | Tab | 当前字母原样输入并加一个空格；无拼音时直接插入空格 |
| 整句翻译 | Ctrl+Option+T | 选中已经输入的句子后请求翻译 |
| 放弃翻译 | Esc | 保留原文 |

1. 输入 nihao，按 Space：你好上屏。随后可移动光标、选择文字并编辑前文。
2. 英文词之间按 Tab。例如 i → Tab → want → Tab → to → Tab → eat → Tab，得到 i want to eat 和末尾空格。
3. 继续输入 zaocan：Space 选早餐，Option+Space 选 breakfast。应得到 i want to eat breakfast，英文前缀不改写。连续 Tab 保留多个空格。
4. 整句话先正常输入和编辑，再选中并按 Ctrl+Option+T；译文在原句下方，点击译文或按 Option+Space 采用。Space / Esc 保留原文。预览期间 Enter 不采用也不转发发送。
5. 输入法设置 → 快捷键：四项分别录制，保存后候选窗口立即显示新绑定。可恢复默认；不能使用 Enter，重复组合和桌面查词占用会提示。
6. 输入法激活期间 Tab 用于空格；需要焦点导航可用 Shift+Tab，或自定义“输入空格”为其他组合。
7. 桌面查词改为 Shift+Option+Space，划词查词仍是 Option+D，避免抢占输入法 Option+Space。
8. 云辅助仍复用桌面模型和 Thinking 设置。采用后的单词收录受已有设置控制，预览不入本。整句选区翻译依赖应用的读取选区接口。

回报问题时注明应用名、按键步骤、实际结果和截图。内核与布局测试不代替所有真实应用输入验收。
