# v0.5.0 输入法操作清单

2026-10-10 · Space 一次确认当前候选，覆盖此前 Space 暂存方案。

| 操作 | 默认按键 | 结果 |
| --- | --- | --- |
| 当前候选上屏 | Space | 一次确认当前选中的源文候选，包含中文里选择英文；不再先暂存再按一次 |
| 选英文 | Option+Space | 采用当前英文候选 / 译文，不发送消息 |
| 输入空格 | Tab | 把当前字母和空格保留在黑框草稿中，不正式上屏 |
| 整句翻译 | Ctrl+Option+T | 翻译黑框内整句；没有草稿时翻译应用选区 |
| 放弃翻译 | Esc | 保留原文 |

1. 输入 nihao，按 Space：你好上屏。随后可移动光标、选择文字并编辑前文。
2. 英文词之间按 Tab。例如 `I → Tab → want → Tab → to → Tab → eat → Tab`，黑框保留 `I want to eat `。连续 Tab 保留多个空格，不把词逐个正式提交到应用。
3. 继续输入 `zaocan`，要直接输入当前原文，按一次 Space 即上屏。要先保留中文草稿供整句翻译，可用数字或点击选择“早餐”，等句下译文准备好后按 Option+Space 采用 `I want to eat breakfast`。也可以直接用 Ctrl+Option+T 预览整句再采用英文，不先按 Space。
4. 整句草稿可用左右方向键移动、Home/End 或 Cmd+左右到首尾、Option+左右按词移动、Backspace/Delete 删除、Option+Backspace 按词删除。前文编辑也支持拼音候选和英文候选，光标后面的文字保留；End/Cmd+右回到末尾。Ctrl+Option+T 请求整句翻译，使用当前高亮候选。译文仍在黑框对应原句下方。没有草稿时，可选中应用文本使用同一翻译快捷键。预览期间 Enter 被拦截，不采用也不转发发送；Esc 放弃译文。
5. 输入法设置 → 快捷键：四项分别录制，保存后候选窗口立即显示新绑定。可恢复默认；不能使用 Enter，重复组合和桌面查词占用会提示。
6. 输入法激活期间 Tab 用于空格；需要焦点导航可用 Shift+Tab，或自定义“输入空格”为其他组合。
7. 桌面查词改为 Shift+Option+Space，划词查词仍是 Option+D，避免抢占输入法 Option+Space。
8. 云辅助仍复用桌面模型和 Thinking 设置。采用后的单词收录受已有设置控制，预览不入本。整句选区翻译依赖应用的读取选区接口。

回报问题时注明应用名、按键步骤、实际结果和截图。内核与布局测试不代替所有真实应用输入验收。

9. 中文里选择英文：例如草稿“例如这种”后输入 `space`，高亮 `space`，Space 或 Option+Space 都应一次采用 `例如这种space`，不改选“是怕侧”，也不把中文前缀改成英文。显式整句翻译时仍可采用整句译文。
10. 输入法设置 → 通用 → “自动记住确认上屏的常用词条”。启用后确认过的词条与使用偏好保存在本机；候选预览、取消、安全输入与关闭学习不新增记忆。自动学习只保存具有可靠读音的中文词条，不猜测编辑后文本的拼音。
11. 输入法设置 → 常用词条 → +：填写小写输入码、正确内容、候选位置后保存，立即参与候选；支持编辑、停用、删除，重启仍保留。这里管理手工固定条目；自动个人词库使用独立 user-words.tsv / user-english.tsv 等文件，与桌面英语生词本不同。
12. 选择短候选后，未选完的拼音应留在候选框内，不能为了一次上屏把剩余文字擅自全部提交。常用词与排序数据每 5 秒及切换/退出时刷新到本机文件。

13. 字典未收录的英文（例如 diffu）也提供原样拼写候选；高亮该候选后可用 Space/Option+Space 确认。不会为了英文输入强制采用近似中文。

14. 前文编辑示例：在“娃问题”前定位光标，输入 xianzaicunzai，选择“现在”“存在”得到“现在存在娃问题”；光标仍在新增文字后，可用 Delete 删除错误的“娃”。新拼音按 Esc 只取消本次拼音，保留已有文字。
15. 代码编辑器里本地译词不受自动辅助抑制影响，例如 yuanxing 高亮“圆形”时，Option+Space 立即采用 circle。无本地译词时，主动按一次英文确认可等云译文就绪后采用；继续编辑、光标移走或切换输入框会取消，失败不写入。
