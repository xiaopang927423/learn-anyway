# v0.5.0 输入法操作清单

2026-10-09 · 最新交互取代此前回车确认方案。

| 操作 | 默认按键 | 结果 |
| --- | --- | --- |
| 选中文 / 原文 | Space | 普通中文词上屏；已有句子草稿时先选入草稿，末尾无待选拼音时确认原文 |
| 选英文 | Option+Space | 采用当前英文候选 / 译文，不发送消息 |
| 输入空格 | Tab | 把当前字母和空格保留在黑框草稿中，不正式上屏 |
| 整句翻译 | Ctrl+Option+T | 翻译黑框内整句；没有草稿时翻译应用选区 |
| 放弃翻译 | Esc | 保留原文 |

1. 输入 nihao，按 Space：你好上屏。随后可移动光标、选择文字并编辑前文。
2. 英文词之间按 Tab。例如 `I → Tab → want → Tab → to → Tab → eat → Tab`，黑框保留 `I want to eat `。连续 Tab 保留多个空格，不把词逐个正式提交到应用。
3. 继续输入 `zaocan`，选中“早餐”后按 Space：它进入同一句草稿。等待句下英文译文，按 Option+Space 一次采用 `I want to eat breakfast`，不发送消息；不需要连续按两次 Space 输入空格。
4. 整句草稿可用左右方向键移动、Home/End 或 Cmd+左右到首尾、Option+左右按词移动、Backspace/Delete 删除、Option+Backspace 按词删除。前文编辑时可直接修改英文；End/Cmd+右回到末尾后恢复拼音选词。Ctrl+Option+T 请求整句翻译，使用当前高亮候选。译文仍在黑框对应原句下方。没有草稿时，可选中应用文本使用同一翻译快捷键。预览期间 Enter 被拦截，不采用也不转发发送；Esc 放弃译文。
5. 输入法设置 → 快捷键：四项分别录制，保存后候选窗口立即显示新绑定。可恢复默认；不能使用 Enter，重复组合和桌面查词占用会提示。
6. 输入法激活期间 Tab 用于空格；需要焦点导航可用 Shift+Tab，或自定义“输入空格”为其他组合。
7. 桌面查词改为 Shift+Option+Space，划词查词仍是 Option+D，避免抢占输入法 Option+Space。
8. 云辅助仍复用桌面模型和 Thinking 设置。采用后的单词收录受已有设置控制，预览不入本。整句选区翻译依赖应用的读取选区接口。

回报问题时注明应用名、按键步骤、实际结果和截图。内核与布局测试不代替所有真实应用输入验收。
