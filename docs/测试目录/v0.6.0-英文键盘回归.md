# 0.6.0 英文键盘回归

日期：2026-10-12。实验性 macOS 输入法；自动化客户端不等于全部宿主人工验收。

## 自动化覆盖

原有 `--interaction-smoke` 场景保持：中文一次 Space、混输英文采用、黑框恢复、前文拼音与后文保留、IDE 显式译词、异步采用取消与学习记录。

新增实际控制器分发与模拟 AppKit 客户端场景：Ctrl+Shift+E 进英文；I 大写；want/to/eat/Diffu/v2 原词 Space 一键一次写入；bre 高亮 breakfast 后 Tab 采用；foo123 数字不选词；Enter 只确认待输入词、为空返回宿主；标点和左右键保留原词且交回宿主；空 Tab 焦点导航；切中文 nihao 一次 Space；IDE 英文直通。配置测试覆盖默认/自定义切换键、冲突回退和旧配置兼容。

## 人工验收清单

1. 安装包升级后检查输入源仍启用、个人词条未丢失；菜单/关于显示 0.6.0。
2. TextEdit、浏览器输入框、Codex 分别输入 I want to eat breakfast，逐词按一次 Space。
3. 选 breakfast 补全并按 Tab；未选补全的 bre 按 Space 保留 bre。
4. 输入 foo123、Diffu、don't、well-known、连续空格、大写；检查标点不被改写。
5. 左右键或鼠标回到之前词条修改，编辑前文后继续输入。
6. 空组合 Tab/Shift+Tab 切换焦点；待输入词 Enter 只确认，翻译预览 Enter 不发送。
7. 用设置录制新中英切换键，重开输入法后检查持久化；与其他快捷键冲突时不保存。
8. Ctrl+Shift+E 和物理 Caps Lock 切换，确认有待输入文本时原文保留、状态栏正确。
9. IDE 维持默认直通；关闭候选/网络断开后仍可输入英文。Secure Input 保留系统处理。
