## 平台验收边界

系统服务只适用于支持 macOS 文本服务的应用；Safari 使用系统服务，未提供独立扩展。真实 Chrome 菜单点击因 Computer Use 权限未授予而未执行；扩展仍需在浏览器开发者模式下加载文件夹。程序化接口 / 本机消息验证不代替实际浏览器菜单点击。

参考：Apple 服务属性：https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/SysServices/Articles/properties.html 。Chrome 菜单接口：https://developer.chrome.com/docs/extensions/reference/api/contextMenus 。
