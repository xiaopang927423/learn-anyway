# WordMate 0.6.0 本地安装包

2026-10-13。独立本地实验版，输入法仍存在 bug，请保留 ABC/系统拼音。后续独立维护，源码与介绍页仅上传到 github.com/xiaopang927423/learn-anyway，不再同步旧案例仓库。

## 安装

1. 双击 WordMate-0.6.0-macOS-arm64.pkg，按安装器提示安装。适用于 Apple Silicon macOS 13 及以上，本机需要 /usr/bin/python3 可用；不需要安装 Rust、Node 或 npm 来运行程序。
2. 打开 ~/Applications/WordMate.app。已有 /Applications/WordMate.app 且可写时会同步升级该副本，保留现有启动路径。
3. 系统设置 → 键盘 → 输入法/输入源 → 添加 WordMate。已启用的输入源保持原身份；未出现时注销并重新登录再添加。安装后查看 ~/Library/Application Support/WordMateInput/install-state.json 的 ready 状态。
4. 选择 WordMate 输入法，单击 Shift 切换中英文。中文数字 1–9 选词直接上屏，Tab 进入草稿；英文 Space 正常空格、Tab 采用补全。
5. WordMate 设置配置现有 OpenAI 兼容模型，开启输入法云辅助；输入法「云服务」开启云联想。中英常用词确认后记忆，重启保留。

## 浏览器翻译

在 Chrome/Edge 扩展管理页开启开发者模式，加载 ~/Applications/WordMate-使用说明/浏览器扩展/。安装器会尝试配置现有 Native Messaging 连接；浏览器扩展仍需手动加载。安装前请确认本机 Python3 可用。若只使用输入法和桌面查词，不依赖浏览器扩展。

插件版本为 0.6.0。已加载旧扩展请在扩展管理页点击“重新加载”；若旧目录不同，确认加载的是新版安装目录。网页支持原位双语和仅译文，双语片段保留强调样式。

正在阅读网络 PDF 时点击插件“翻译页面内容”或“当前 PDF 双语对照”：原标签直接显示原版/译文，自动读取并翻译，不新开标签，也不再选择一次文件。网络读取按当前站点请求权限。可点击“返回原 PDF”回到原地址；仅内置 PDF 页会由扩展在同标签接管显示，普通网页继续原位翻译。需登录的 PDF 请下载后使用“更换文件”入口本地打开。左侧原版，右侧译文；点击“翻译当前页”或单段按钮，点击段落定位原文，划词可加入生词本。同标签翻译入口自动补译翻页，点击停止/恢复即关闭；备用手动打开文件时默认关闭。仅支持文字层 PDF，扫描件 OCR、译文导出和密码输入不包含。

## 数据与备份

模型设置和学习库仍在 ~/Library/Application Support/WordMate/；输入法配置与词条仍在 ~/Library/Application Support/WordMateInput/。安装器不覆盖这两处的数据文件。旧应用备份在 ~/Library/Application Support/WordMate/local-installer-backups/ 的时间戳目录。

安装包整体遵循 GPL-3.0；上游、依赖和词库的原始许可保留。本地包未做 Developer ID 公证。本包不携带个人密钥，不自动安装浏览器扩展，不上传代码或数据。

## 本地重新打包

先按现有项目流程构建桌面和输入法，然后运行 python3 scripts/package-local.py。输出位于 dist，含安装包、SHA-256 校验文件和本说明。继续使用本地 Git，不推送远端。
