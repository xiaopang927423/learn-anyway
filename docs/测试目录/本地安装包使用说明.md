# WordMate 0.6.3 本地安装包

更新于 2026-11-19。独立本地实验版，输入法仍存在 bug，请保留 ABC/系统拼音。后续独立维护，源码与介绍页仅上传到 github.com/xiaopang927423/learn-anyway，不再同步旧案例仓库。

## 安装

1. 双击 WordMate-0.6.3-macOS-arm64.pkg，按安装器提示安装。适用于 Apple Silicon macOS 13 及以上，本机需要 /usr/bin/python3 可用；不需要安装 Rust、Node 或 npm 来运行程序。
2. 已有 /Applications/WordMate.app 时在原位置升级，并移除安装器暂存的用户目录副本；否则打开 ~/Applications/WordMate.app。桌面应用只保留一个安装位置。现有应用不可写时会在安装前停止，避免留下两个版本。
3. 系统设置 → 键盘 → 输入法/输入源 → 添加 WordMate。已启用的输入源保持原身份；未出现时注销并重新登录再添加。安装后查看 ~/Library/Application Support/WordMateInput/install-state.json 的 ready 状态。
4. 选择 WordMate 输入法，单击 Shift 切换中英文。中文数字 1–9 选词直接上屏，Tab 进入草稿；英文 Space 正常空格、Tab 采用补全。
5. WordMate 设置配置现有 OpenAI 兼容模型，开启输入法云辅助；输入法「云服务」开启云联想。中英常用词确认后记忆，重启保留。

## 浏览器翻译

在 Chrome/Edge 扩展管理页开启开发者模式，加载 ~/Applications/WordMate-使用说明/浏览器扩展/。安装器会尝试配置现有 Native Messaging 连接；浏览器扩展仍需手动加载。安装前请确认本机 Python3 可用。若只使用输入法和桌面查词，不依赖浏览器扩展。

插件版本为 0.6.3。已加载旧扩展请在扩展管理页点击“重新加载”；若旧目录不同，确认加载的是新版安装目录。网页支持原位双语和仅译文，双语片段保留强调样式。

正在阅读网络 PDF 时点击插件“翻译页面内容”或“当前 PDF 双语对照”：原标签直接显示原版/译文，自动读取并翻译，不新开标签，也不再选择一次文件。网络读取按当前站点请求权限。可点击“返回原 PDF”回到原地址；仅内置 PDF 页会由扩展在同标签接管显示，普通网页继续原位翻译。需登录的 PDF 请下载后使用“更换文件”入口本地打开。左侧原版，右侧译文；点击“翻译当前页”或单段按钮，点击段落定位原文，划词可加入生词本。同标签翻译入口自动补译翻页，点击停止/恢复即关闭；备用手动打开文件时默认关闭。仅支持文字层 PDF，扫描件 OCR、译文导出和密码输入不包含。

## 数据与备份

模型设置和学习库仍在 ~/Library/Application Support/WordMate/；输入法配置与词条仍在 ~/Library/Application Support/WordMateInput/。安装器不覆盖这两处的数据文件。旧应用以 ZIP 备份在 ~/Library/Application Support/WordMate/local-installer-backups/ 的时间戳目录；开发安装命令的备份在 app-backup/。如需恢复，请先解压到临时目录，再替换正式安装，不要长期保留多份 .app。

安装包整体遵循 GPL-3.0；上游、依赖和词库的原始许可保留。本地包未做 Developer ID 公证。本包不携带个人密钥，不自动安装浏览器扩展，不上传代码或数据。

## 本地重新打包

先按现有项目流程构建桌面和输入法，然后运行 python3 scripts/package-local.py。构建应用分别放在 wordmate/dist/build.noindex/ 和 input-method/bundle/build.noindex/，避免被启动器当成已安装应用。输出安装包位于 dist，含 SHA-256 校验文件和本说明。版本以根目录 release.json 为准，运行 python3 scripts/versions.py 校验后再打包。安装包不进入 Git 历史；本次交付为本地安装包。

2026-10-14：本次网页/PDF 更新版为 0.6.1，随包输入法独立版本仍为 0.6.0。

## 0.6.2 桌面 / 0.6.5 输入法更新

输入法菜单 → 设置 → 词库：可检查更新、更新已启用词库，或单本下载/更新/修复。自动更新默认每天检查一次；离线时继续使用已有词库。通用扩展词库请按需下载。

同页“记住我的选词习惯、人名和常用短语”控制个人学习。个人记忆保存在本机，不上传给词库源；公共词库更新不会覆盖它。新词库等待本轮输入结束后生效。

桌面查词已加入模型 JSON 格式恢复；旧接口不支持 JSON mode 时自动兼容，不需要修改密钥或重新导入学习库。

## 0.6.3 桌面 / 0.6.7 输入法更新

查词页选择“句子翻译 / 语法检查”，输入中文可翻译为英文，输入英文会显示翻译、错误片段、修正版和中文解释。“需要修正”和“可选建议”分开显示。普通查询中的英文句子也会自动检查。

英文输入暂停约 1.2 秒且当前单词已提交后，输入法会检查光标前的一句英文。建议窗支持复制、关闭和明确采用；采用前会核对原文与光标位置，文字已修改时不替换。桌面设置中的“英文输入语法与表达检查”可关闭此功能。检查通过现有模型接口发送当前句子，不加入个人学习库；密码框、隐私模式和排除的应用不检查。宿主不支持读取原文时不会提供原位替换。

本次加入 IMK 多种输入回调兼容和升级时重新启动服务。浏览器数字、Shift 切换仍需以实际键盘验收为准：此前构建 6071 的用户反馈仍然失败，构建 6072 已安装待确认，不能用自动化按键成功代替。升级后请在浏览器菜单栏重新选择 WordMate；`ready` 仅表示输入源已注册启用，不代表已通过宿主输入测试。
