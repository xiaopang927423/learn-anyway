# 测试计划

## 自动化分层

| 层 | 命令（wordmate 目录） | 内容 |
| --- | --- | --- |
| 规范 | npm run lint | JS / Python 语法、目录和文档链接、版本与锁文件一致 |
| 单元 | npm test | 模型参数和 JSON、缓存隔离、扩展注入与消息、失败回传 |
| 网页渲染 | npm run test:browser | 真实 Chromium DOM、双语段落、原链接、恢复、动态文本、停止、选词安全渲染 |
| 桌面 / 数据 | npm run test:integration | 独立临时数据库、事务、幂等、队列同步、编辑撤销、导航草稿、浏览器 socket |
| 构建 | npm run dist | macOS arm64 原生 ABI、应用与扩展资源打包 |

自动化模型调用使用 stub。集成测试不写真实学习库。故障注入产生的模拟 IPC failure 日志属于测试预期，断言要求失败后可重试且不重复计分。

## 手动发布验收

- Chrome / Edge 加载扩展并确认权限；右键整页 / 选区入口实际存在。
- 普通文章页段落译文与链接布局可用；选词浮层靠近选区；Shift 段落翻译、停止、恢复、复制可用。
- 禁止注入页面给出清晰提示；断开桌面、无 Key、错误模型、超时后可重试。
- 真实 Diffu 请求通过 Native Messaging 返回结果，不弹出桌面查词窗。
- macOS 文本服务收到完整中文 / 英文选区；服务与浏览器入口分别验证。

自动测试通过不能替代真实浏览器点击。若 Computer Use 权限不可用，测试结果必须明确记录未执行的点击验收。

## 阅读 / Thinking / 入本发布检查

切换上下双语和仅译文，检查链接、强调、布局和模式切换零新增请求；网页动态更新后恢复原文仍保留新内容。开 / 关 Thinking 请求参数必须传到服务端，并用真实 reasoning_tokens 验证 Diffu 关闭。主动 / 自动入本和重复点击需使用临时数据库断言。

## 边界矩阵

以 [翻译边界](../产品需求目录/翻译边界.md) 为覆盖合同。每次改变边界同时执行文章、仓库、社交信息流和搜索 / 知识面板夹具；验证可读内容覆盖与控件 / 身份保护，不能只验证本次截图对应的网站。浏览器仍需手动验收，不能将 DOM 夹具称作线上覆盖率。

## 重启连接验收

运行 npm run test:host，模拟陈旧 / 缺失 socket 和重复安装路径。桌面测试必须验证应用运行中 socket 删除后的修复。安装到现有开机路径后，使用真实 Native Messaging 验证 get-preferences；关闭应用再由 Host 自动唤起验证冷启动。应用冷启动模拟不等于已经执行整机重启。
