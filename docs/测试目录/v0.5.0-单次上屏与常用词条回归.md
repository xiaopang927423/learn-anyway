# v0.5.0 单次上屏、候选恢复与常用词条回归

日期：2026-10-10。实验性开发组件，仍存在大量已知及未知 bug，不宣称完成所有宿主验收。

## 修复

- 原文确认不再先暂存：一次 Space 采用当前高亮候选，包括混输英文；高级组句开关不拦截该确认。短候选上屏后保留未选拼音。
- 英文源候选的 Option+Space 同样采用原文，保留周围中文；显式整句翻译仍采用整句结果。
- 空本地查询提供原文候选；输入仍存在却会话为空时重新生成候选、恢复窗口，不等云返回或要求再按 Space。
- 确认源文写入后才记录源文选择。中文词条仅从可靠候选读音组成，自动保存到个人词库并影响后续候选；关闭学习、安全输入、改写文本不新增该记忆。
- 通用页自动记忆开关和“常用词条”手动新增/编辑/停用/删除入口。复用已有配置保存，不覆盖原个人数据；定时持久化从 60 秒缩短到 5 秒，停用/退出仍刷新。
