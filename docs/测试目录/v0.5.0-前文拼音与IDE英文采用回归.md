# 前文拼音与 IDE 英文采用回归

日期：2026-10-11。实验性开发组件；仍不宣称全部真实宿主兼容性完成。

## 问题与实现

此前前文编辑直接追加字母，xianzaicunzai 无法转成中文。现在冻结文本与待选 token 分开，token 在编辑锚点插入并通过基础引擎出候选；暂存、展示、翻译和确认统一保留原后文。前文可拼音选字、选择英文、删除和取消新拼音；可读取标记范围的宿主在下一键同步鼠标光标。部分确认保留未选拼音和后文，不移到句尾。

IDE 自动辅助限制曾连带抑制主动英文键的本地结果。现在本地 circle 等译词立即采用；无本地结果时记住确认意图，结果就绪后只写入一次。意图绑定代次、活动客户端、源文、范围和光标；编辑/导航/换字段/失败/范围变化取消。定时回调释放 Host 借用后再采用，避免重入。
