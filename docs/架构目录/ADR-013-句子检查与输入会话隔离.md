# ADR-013 句子检查与输入会话隔离

## 结构化结果

`sentence-review.js` 定义独立模型协议。模型返回准确引用片段、出现序号、替换内容、类别、严重程度和中文解释。主进程从原句计算 UTF-16 范围，拒绝不存在、重叠或无变化的片段，并按倒序替换构造修正版；不信任模型提供的偏移或整句改写。格式错误沿用有限重试，主动取消与超时分开处理。

查询模式参与缓存键。英文多词输入自动检查，中文可通过显式句子模式检查翻译。渲染器转义全部模型文字，编辑输入会递增请求序号，使旧结果失效。

## 输入法边界

本机认证 socket 新增 `grammar.check`。请求检查设置开关与长度，经过共享队列，30 秒取消；请求完成后重新验证设置版本。不会触发生词本学习或持久化输入句子。

Rust 使用独立 worker、代数编号与 1.2 秒防抖。主线程读取支持 IMK 的宿主文本，后台只处理快照。模型返回时以及用户采用时均核对原句与 UTF-16 选区；新输入、模式切换、停用、隐私或安全输入取消旧工作。浮窗不自动替换、不抢占输入焦点。

按键入口支持 NSEvent、拆开的键码事件、文本与编辑命令回调，适配后复用相同选择和直输逻辑。未收到修饰键事件的会话使用定时器检测 Shift 边沿；收到原始修饰键事件的会话使用原有精确事件状态机。组合键输入取消单击切换。

## 安装生命周期

升级前使当前 WordMate 会话退出，停止旧进程后替换；注册新包并启动服务，恢复升级前正在使用的 WordMate 输入源。仅 TIS 启用状态为真不能代表宿主已重连。旧应用备份与构建隔离见 ADR-012。

## 验证边界

模型格式、取消、渲染及模拟 IMK 属于自动回归；真实模型调用只验证固定公开测试句；Chrome 真实键盘验收独立记录。
