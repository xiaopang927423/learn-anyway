# 版本与发布管理

根目录 release.json 是唯一版本配置。version 为整体产品版本，desktop/extension 跟随整体版本，inputMethod 为独立组件版本。当前产品 0.6.1 包含输入法 0.6.0；上游 Rust crate 版本不参与发行号。

修改 release.json 后运行 python3 scripts/versions.py --sync，再运行 python3 scripts/versions.py。同步应用、扩展、依赖锁、输入法 plist 和当前官网/安装说明。历史 CHANGELOG 和旧验收记录不重写。输入法发生改动时，单独修改 inputMethod 和 inputMethodBuild，再重新构建。

提交检查及打包必须通过版本核对，构建产物 plist 也必须匹配。安装包旁的 .release.json 记录源提交、未提交改动标记、组件版本、大小和 SHA-256；dist/current-release.json 指向最后一次打包结果。旧包保留历史文件名，不改名冒充新版。

发布标签在源码冻结后创建为 v<产品版本>。GitHub Release 上传同版本 pkg、sha256、release.json 和安装说明。大包不进入 Git。最终以实际资产列表与校验值为准，标签创建不等于完成二进制发布。
