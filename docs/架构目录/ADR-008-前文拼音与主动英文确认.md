# ADR-008 前文拼音编辑与主动英文确认

日期：2026-10-11（2026-10-10 开始），实施。修订前文只接受字面英文的限制。

冻结的整句保存在草稿中，draft_cursor 表示插入锚点；新输入的中间拼音由基础引擎处理。所有展示和候选源文统一用 composition_text 在锚点插入当前 token，光标为锚点加 token 光标。暂存候选时插入锚点并推进，不追加到句尾，所以保留后文。前文英文候选、Tab 原文空格、中文候选转换都使用这条路径。

删除未确认拼音时只改基础输入缓冲；普通方向键可编辑拼音，首尾/跨 token 先冻结当前选择再移动。宿主提供有效 markedRange/selectedRange 时，在下一键同步鼠标光标位置，UTF-16 转字符位置。编辑中的 Esc 取消新拼音并保留已冻结文本；无拼音时 Esc 退出编辑。

部分中间候选确认时，先提交光标前选定内容，把未选拼音及原后文留在新草稿锚点 0，不把未选拼音接到原句末。源文写入使用实际 preedit/caret，不能以裸拼音长度代替带分隔符的标记长度。

自动辅助在 IDE 被抑制，不代表用户主动英文确认被禁用：存在本地译词时直接采用；缺失时显式请求翻译并保存一次确认意图。50ms 轮询在释放 Host 借用后调用采用，避免重入 RefCell。意图绑定 generation、活动客户端、源文、范围和光标；继续输入/导航/离开字段、请求失败或状态不符取消。预览译文尚未到达时的确认也保留意图，不要求再次按键。不模拟 Enter、不触发应用发送。

测试以控制器事件和模拟客户端验证；IDE 的具体输入组件及异常仍需真实应用验收，实验性声明不变。
