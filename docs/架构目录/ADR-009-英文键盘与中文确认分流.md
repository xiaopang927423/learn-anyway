# ADR-009 英文键盘与中文确认分流

日期：2026-10-12。关联 [0.6.0 PRD](../产品需求目录/PRD-v0.6.0-英文键盘.md)。

## 问题与选择

0.5.0 的全局确认快捷键在英文文本处理前拦截 Space/Tab，导致英文空格执行中文上屏、整句草稿和英文词补全共用状态。0.6.0 增加独立英文控制器模块 `imk/controller/english.rs`；不另建词库、模型或系统输入源。

按键顺序为：登录/Secure Input 防护 → 会话与标记同步 → 中英切换键 → 英文键盘（排除主动翻译和翻译确认）→ 中文确认键与翻译预览 → 既有命令/中文文本处理。英文输入的普通数字不进选词映射，Space 不调用候选确认，Tab 显式调用原有确认路径。

## 模式与会话

`imk/modifiers.rs` 持有主线程模式覆盖值与最近 Caps Lock 状态；单击 Shift 松开及自定义组合键改变覆盖值，实际 Caps Lock 状态变化清除覆盖值。菜单栏显示有效模式。模式不与大写输入绑定：软件切换后字母保留事件实际字符。输入源身份保持原有 Hans，升级不重新注册一套身份。

切换时提交原始组合，取消后台预测和旧采用意图，避免延迟译文写入新模式。英文单词使用现有 Engine English 查询与 Host Session；英文 marked text 始终行内显示，用户看见打入的字母。Space 使用一次宿主 insertText 写入原词加空格，并清空组合；无词条仍能打原文。Tab 采用高亮候选与既有确认学习。普通英文补全不启动云联想或自动翻译；主动翻译仍走既有 TranslationJob 与防误发送路径。

左右/Home/End 等跨词编辑动作先确认原始待输入词，再返回 false 由宿主执行，从而无需复制整句到输入法草稿。宿主焦点导航和命令组合保持通路。IDE/终端继续用既有 english_candidates_off 策略直通。

## 配置与部署

新增 `[shortcut] toggle_english`，默认 `control+shift+e`，沿用 KeyRecorder、配置热更新、冲突检测和恢复默认按钮；旧配置自动补缺省。无新增网络权限、数据库表或模型调用。原生组件、Info.plist、构建和安装包升级 0.6.0-dev/0.6.0；桌面与扩展版本保持其原有版本。本组件仍为实验性开发包。

验证覆盖直接事件分发、模式切换、字母大小写、数字、原词空格、显式补全、焦点导航和既有中文回归。真实 IMK 宿主与系统 Caps Lock 事件仍需人工验收。

单击 Shift 使用既有 switch_mode.shift 字段，FlagsChanged 和 KeyDown 共用每控制器的单击状态；失焦/组合键取消，备用组合键仍可自定义。设置录制统一鼠标/performClick/AccessibilityPress 的入口。原生可使用 --preferences 直接打开设置，不启动第二个 IMKServer。
