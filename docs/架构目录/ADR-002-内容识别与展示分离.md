# ADR-002：内容识别与展示分离

日期：2026-10-08 · 状态：采用

## 背景

对所有 div/a 翻译会破坏文件行和操作栏；改为 article/p 白名单后，又漏掉社交帖、搜索摘要和知识面板。按网站追加标签不能形成稳定边界。

## 决策

统一扫描可见 DOM，硬排除真实控件、编辑 / 隐藏 / 代码内容，再识别语义段落和叶级信息单元。侧栏和排版标签不是禁止条件。文件浏览器与身份标识单独识别；普通信息表格不因 table/grid 被忽略。

识别决定“哪些内容可读”，布局策略决定“在哪个单元展示”。译文不会作为父级列表 / 网格的独立项；flex/grid 的阅读单元可以局部换行，截断可以局部解除，所有修改记录用于恢复。原链接与源节点保持。

## 替代方案与限制

拒绝全 div 盲译，也拒绝只扫描一个文章根节点。此方案使用 DOM / 样式启发式，仍需不同网站结构与真实浏览器回归；不会承诺图片、关闭 shadow root 或浏览器禁止注入的页面可译。

每次改变识别规则，文章 / GitHub 文件浏览器 / 社交引用帖 / 搜索和知识面板夹具必须共同通过，避免修一个页面破坏另一个。
