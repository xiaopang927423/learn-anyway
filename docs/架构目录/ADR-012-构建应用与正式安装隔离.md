# ADR-012 构建应用与正式安装隔离

状态：采用，2026-11-19。

问题有两个来源：安装脚本将新版复制到系统目录后仍保留用户目录副本；源码构建和旧版备份是普通 .app，进入 Spotlight 与 LaunchServices。

Electron 输出调整为 wordmate/dist/build.noindex，原生输出调整为 input-method/bundle/build.noindex。构建、安装、打包脚本统一使用这些位置，不通过旧路径的符号链接兼容，避免重新暴露生成应用。

desktop-bundle.py 供开发安装与组合安装包共用。安装目标优先沿用已有系统目录；全新安装落在用户目录。组合安装器的 preinstall 先检查身份和权限、停止旧进程并归档，postinstall 再同步系统目录、验签，成功后注销并删除重复的用户应用。复制或签名校验失败时不删除用户副本。

备份使用带时间戳的 ZIP。开发安装验证 ZIP CRC 和必需的 Info.plist 后才覆盖旧应用。安装包预安装备份和输入法现有 ZIP 机制保留。

本机历史清理单独执行：仅注销 WordMate 家族的非正式路径，旧生成应用和旧备份放入废纸篓；不重建全机 LaunchServices 数据库，不改变其他应用排序和注册信息。个人数据目录不参与清理。
