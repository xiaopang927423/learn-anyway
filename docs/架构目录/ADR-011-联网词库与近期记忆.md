# ADR-011：联网词库与近期记忆

状态：已实现，2026-11-18。桌面 0.6.2，输入法 0.6.5。

## 公开词库

`qingjian-update::dictionaries` 使用 Qingjian 官方 `qingjian-dicts` 的 index.json 和逐词库 Release manifest.json。清单同时查询 GitHub/Gitee，下载可回退镜像；固定 HTTPS 来源，无任意远端 URL 或输入文本上传。内置 2026-11-18 清单作为初次离线展示，成功检查后缓存最新清单。仅展示官方中文 extra 类别，未来格式提示升级。

清单上限 512 KiB，压缩内容上限 64 MiB，解压上限 256 MiB。下载采用有界 chunk 读取，校验标签、版本、大小、SHA-256、文件名、QJ 格式与非空内容。校验值来自同一官方 HTTPS Release，用于完整性校验，不宣称独立签名认证。保留 QJ 来源、许可证和署名；版本写入同一 QJ 文件后原子改名。进程间文件锁避免 IMK 进程和独立设置窗口同时写入。

路径：`~/Library/Application Support/WordMateInput/dicts/online/`。同名在线领域词库优先于随包领域词库，损坏或空文件回退；同一本只加载一次。手工导入仍在 dicts 顶层，个人学习文件仍在数据目录根层。网络线程用消息传递返回进度和完成状态；主线程每秒检测文件新增、移除和原子替换（含独立设置进程下载），只在 composition 和 preedit 都结束后切换引擎词库，避免打断翻页、数字选词。每天自动检查已启用的 domains，失败在本次进程中最多每小时重试，手动操作可立即重试。

原有手工导入也改为临时文件 + 原子改名，避免覆盖正在 mmap 的文件；支持 UTF-8 BOM 的 TSV/Rime 文件。

## 个人记忆

保留 user.tsv、user-choices.tsv、user-words.tsv 等文件。新增 `user-recent-choices.tsv`，每个输入串保留最近 16 次确认的先后顺序。`Learner::choice_weight` 仍返回累计次数；新的 `preference_weight` 用于排序：`min(累计次数,15) + 16 × 最近窗口次数`。其他 Learner 实现默认返回原计数，保持兼容。

撤销最近选择时从窗口移除对应记录，删词时删除其近期记录。MutedLearner 沿用私密和学习关闭的写入门控。新文件沿用原子写入与仅用户可读权限，原有每 5 秒及停用时保存流程保持。联网升级不读写这些文件。

## 桌面 AI 查词

桌面 `ai.translate` 添加 JSON mode、有限格式重试、长度原因诊断和定义字段校验。最多一次格式重生成，加一次不支持 JSON mode 的兼容回退，总计最多三次 HTTP 请求，均共享 45 秒超时。只对明确提及 response_format/json_object 的 400/422 响应降级参数；401、拒绝等直接报告。网页翻译和输入法候选协议不改。无法恢复时继续现有本地词典兜底。
