# ADR-007 单次确认与个人词库

日期：2026-10-10，实施。覆盖 ADR-006 中 Space 对待选中文先暂存的行为。

原文确认独立于暂存选择：Space 调用一次确认路径，即使启用高级组句，也直接采用当前候选。不跳过混输英文候选。短候选只提交自身与已暂存前缀，剩余拼音继续编辑。英文候选的 Option+Space 采用原文，不把中文前缀翻译；显式整句译文采用走独立路径。

查询无结果时提供可选原文；render 发现组合尚在但会话无候选时重查本地、补原文并恢复窗口。正常高亮不重排，也不要求云端返回才显示。安全输入和未激活的输入源仍遵守系统限制。

源文候选先暂存消耗，再对客户端执行一次写入；确认后才回放选择学习。中文个人词条由确认后的候选读音合并得到，字数与读音必须对应，且仅保存 2–32 字的中文条目。英文沿用个人英文表。个人词库使用现有 FrequencyLearner，与本地配置开关及安全模式保持一致，每 5 秒、停用/退出刷新。手工常用词条复用配置编辑器，不清空已有词库。

回归覆盖一次 Space、混输英文两个确认键、部分输入剩余、窗口/候选重建、学习开关与安全模式、保存后重载召回。真实宿主应用兼容性仍独立验收，不升级为稳定产品承诺。
