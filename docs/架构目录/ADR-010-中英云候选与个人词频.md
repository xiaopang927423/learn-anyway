# ADR-010 中英云候选与个人词频

2026-10-12，0.6.0。用户确认实时云联想，采用后保存个人词库。

原有中文 Compose 请求与拼音校验继续使用；新增 PredictionKind::English，以英文前缀及有限上下文请求单词补全。英文至少3字符且长度不超过64，最多发送前64/后32字符；不发送标点串和纯数字；slots=0 或私密输入时不请求。BridgePredictor 停键约300ms提交最新请求，桌面复用现有模型、Thinking 与凭证，沿用输入优先队列和5秒超时。原文/模型结果用JSON数据字段传输，不作为指令。

桌面 prediction.query 接受 english，响应仍为 words/text/syllables；英文无需拼音。英文单词只允许字母数字、撇号、下划线及连字符，不超过64字符，必须匹配当前前缀、去重并限制数量；不返回整句。Core再次校验，按输入大小写调整；代次不匹配的结果丢弃。中文词仍须音节数量、合法拼音及输入匹配校验。

Host把英文云词转为 English 候选，补入既有云槽位；不自动改写或移动本地候选。用户翻页或高亮进入云槽位后不异步重排。用户Tab/点击采用经现有确认流程上屏后，英文记录频次并写user-english.tsv；中文云词使用既有词频、输入选择及带拼音个人词库。预览不学、取消/过期不学；学习开关关闭后不新增。

新增 Learner.english_weight 合并英文原词使用次数和候选选择频次，避免Space直接输入不影响排序；沿用本地词表、5秒定时保存和停用时保存。个人输入词频用于补全排序，复习熟练度仍由复习/默写记录计算。联网是当前输入的可选候选，不是下载词包或上传个人词库。断网保留本地输入。

--prediction-smoke 使用固定英文/中文测试样本检测真实配置的模型，只打印候选数量，不写学习记录。完整真人IDE候选操作不由此命令代替。

## 2026-10-29：确认短语的云候选读音校验

直接上屏与确认草稿短语共用 `learned_syllables_for(candidate, keys)`。确认短语不能直接拼接云候选原始 syllables：暂存片段保存其原始按键，确认时逐片段解码并校验；输入能完整对应字数及逐字读音时优先输入读音，否则仅接受可核实的模型读音。任一云片段无法通过现有读音规则校验时，跳过整个短语的造词，不影响已经确认的文本上屏。

该处理不修改实时 composition，避免读到 commit_staged 消耗后的空缓冲区或其他片段按键；非云候选继续使用其词库读音。私密和学习开关仍由 MutedLearner 约束。未知字沿用原有校验边界，不推断或批量修复历史个人词条。

## 2026-10-29：同输入下的候选偏好

拼音和形码查询使用 `rank_with_choices`：预选前计算廉价的输入选择次数，避免已选词先被其他输入产生的全局词频淘汰；语言模型得分仍只计算预选保留的命中。排序前两项保留精确命中和覆盖长度，同输入选择次数提前到简拼及末音节结构规则之前。原 `rank` 入口保留兼容。

拼音管线在整句和英文插入后，稳定提升覆盖整个当前输入作用域的已选中文候选，避免后来插入的自动整句覆盖个人偏好。前置英文分组保留已由中英设置及使用记录决定的位置，自定义短语、快捷及 emoji 候选仍由后续既有插入流程处理；辅码筛选不走此次提升。前缀词不借短输入的记录压过更长输入的完整候选。

不引入新词库格式或网络学习，沿用 `record_choice` / `choice_weight`、双拼解码后的输入键、FrequencyLearner 保存与重载、确认后学习及 MutedLearner 开关。排序使用累计选择次数；本次未实现时间衰减，不自动修复历史错误个人词条。

## 2026-10-29：分段人名与跨拼法召回

`commit_staged` 重建已暂存片段及剩余拼音，每个片段按保存的按键长度限制作用域，保留后续按键；提交时的 buffer_left / same_buffer 仍表达原输入关系。首片段记住整串的解码学习键，后续片段由原有 finish_buffer 累积为完整词。空按键的编辑/原样片段单独重放，不消耗后续候选。用量仍只计一次最终提交。

完整词和已确认短语除了实际输入键，还在二者不同时记录经校验的完整读音偏好。读音别名记入 LastCommit，退格改选时一并撤销；未写入的静音学习不增加别名撤销记录。remember_confirmed_phrase 避免重复记录 finish_buffer 已记录的同一输入选择，并逐片段解码双拼键。云词的自动造词也只使用 learned_syllables 的已验证读音，无效云片段不进入合词。

词级排序在命中全部音节位置时读取完整读音偏好，因而全拼记住的人名也能从简拼和混合拼音召回；提升整句后候选时再次核对音节位置、覆盖范围和显式分隔。原输入偏好及完整读音偏好取较大值，不将两者相加放大频次。原有词库与学习文件格式不变。

整句插入时，若首条整句来自另一分音，而词级列表存在完整拼写且符合显式分隔的词，则将整句放在这些完整词之后；相同分音的上下文整句及用户确认的读法仍走原策略。此变更修正贪心分词对候选的影响，不依赖下载或替换词库。

## 2026-11-18：0.6.4 候选快照与导航

`Session.navigated` 表示开始查看候选，包括没有移动的边界键和矩阵展开。本地异步重排及云词插入共用这一门槛，翻回首页仍不改本轮候选顺序；空问字结果保留接收首次答案的能力。前文尚未导航时仍可接收正常异步结果，此版不承诺停键后永不更新候选。

Host 的 `prepare_candidates` 供控制器刷新、空窗口恢复、本地模型回调共用，统一英文上下文优先、大小写精确原文候选和草稿兜底。原文由 `typed_scope()` 构造，与提交消耗范围一致。模型回调只更新候选，保留已发给 IMK 的 preedit 与草稿光标，不直接以内核的拼音 preedit 覆盖。

数字选词遵守当前页编号；英文实际 NSEvent 路径与 text 回调均在追加数字前尝试确认候选。缺失字符的物理数字事件按数字行/小键盘键码恢复文本后分发；计算式与 Unicode 路径仍保留数字内容。英文翻页命令先于原文提交，草稿编辑中的配置翻页键先于冻结文本。安装脚本从 release.json 选择包；package.py 在签名与打包前校验 bundle 的 version/build。
