# ADR-010 中英云候选与个人词频

2026-10-12，0.6.0。用户确认实时云联想，采用后保存个人词库。

原有中文 Compose 请求与拼音校验继续使用；新增 PredictionKind::English，以英文前缀及有限上下文请求单词补全。英文至少3字符且长度不超过64，最多发送前64/后32字符；不发送标点串和纯数字；slots=0 或私密输入时不请求。BridgePredictor 停键约300ms提交最新请求，桌面复用现有模型、Thinking 与凭证，沿用输入优先队列和5秒超时。原文/模型结果用JSON数据字段传输，不作为指令。

桌面 prediction.query 接受 english，响应仍为 words/text/syllables；英文无需拼音。英文单词只允许字母数字、撇号、下划线及连字符，不超过64字符，必须匹配当前前缀、去重并限制数量；不返回整句。Core再次校验，按输入大小写调整；代次不匹配的结果丢弃。中文词仍须音节数量、合法拼音及输入匹配校验。

Host把英文云词转为 English 候选，补入既有云槽位；不自动改写或移动本地候选。用户翻页或高亮进入云槽位后不异步重排。用户Tab/点击采用经现有确认流程上屏后，英文记录频次并写user-english.tsv；中文云词使用既有词频、输入选择及带拼音个人词库。预览不学、取消/过期不学；学习开关关闭后不新增。

新增 Learner.english_weight 合并英文原词使用次数和候选选择频次，避免Space直接输入不影响排序；沿用本地词表、5秒定时保存和停用时保存。个人输入词频用于补全排序，复习熟练度仍由复习/默写记录计算。联网是当前输入的可选候选，不是下载词包或上传个人词库。断网保留本地输入。

--prediction-smoke 使用固定英文/中文测试样本检测真实配置的模型，只打印候选数量，不写学习记录。完整真人IDE候选操作不由此命令代替。
