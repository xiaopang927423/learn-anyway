# 首屏动画架构

website/scene.js 用六阶段状态机控制 scene.css 与 index.html 的聊天场景。草稿和候选来自固定示例，使用 textContent 创建，候选只在阶段 2–4 可见；阶段 5 确认英文，阶段 6 继续输入。原文与译文垂直对照，匹配输入法候选布局。

每 100ms 推进展示时钟，离开视口或页面隐藏时暂停推进。语言切换只更新说明，不重置演示。prefers-reduced-motion 下静态展示第四步。首屏不再提供播放、步骤、重播控件。浏览器无模型网络请求和宿主键盘事件，不触碰个人数据。公开接口 WordMateScene 供本地渲染检查。
