# ADR-005：候选确认与空格独立快捷键

2026-10-09 · 已实现；用户最新指示优先，替代 ADR-004 默认整句暂存及回车确认。

默认普通输入：Space 选中文 / 原文，Option+Space 选英文，Tab 原样提交当前字母并插入空格。无候选时 Tab 也插入空格，Shift+Tab 保留应用导航。正常选词立即上屏，前文由宿主应用编辑；高级暂存关闭。高级模式若有历史待确认草稿，方向键先提交原文再交给宿主移动光标。

配置新增 shortcut.confirm_original、confirm_translation、insert_space；整句翻译继续使用 translate_selection。KeyCombo 支持 Space / Tab 的物理键以及修饰组合，禁止 Return / Enter；配置序列化往返、重复冲突、桌面保留组合均检查。录制器支持无修饰 Space / Tab。候选 footer 从有效配置动态生成，不写死按键。

原文键优先选择中文解释；英文键遇到已有英文候选直接提交，不等待模型。字间空格与选词分离，Tab 原样提交英文并插入一次空格；不依赖连续两次 Space。整句先输入与编辑，明确选区后翻译，采用仍验证来源和选区。翻译预览中的 Return 吞掉并提示，不发给宿主发送。鼠标原文 / 译文操作保留。

桌面全局查词移至 Shift+Option+Space，划词仍 Option+D，解决 Electron 全局快捷键抢占输入法 Option+Space。新增设置冲突时不写入配置并显示错误；手改冲突配置使用默认组合兜底。
