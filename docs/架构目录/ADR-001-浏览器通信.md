# ADR-001：浏览器复用桌面模型配置

日期：2026-10-08 · 状态：采用

## 问题

原扩展仅通过 wordmate:// 打开桌面窗口，无法取得翻译结果并在网页显示。扩展不应另存 Diffu Key，也不应开放无鉴权的本地 HTTP 服务。

## 决策

Chrome Native Messaging host 接收文本，连接当前用户 0600 Unix socket，桌面返回结构化结果。整页段落使用独立翻译提示词和缓存，选词复用原词典逻辑。后台启动桌面不抢浏览器焦点。

## 替代方案及影响

直接在扩展存 API Key 会重复配置且扩大密钥暴露面；桌面协议只能单向唤起，适用于系统服务但不能回传网页结果；本地 HTTP 需要处理跨域、网络暴露与额外鉴权。

采用方案需要安装 host 和保持桌面后端可启动；仅 macOS 当前实现，其他操作系统需另实现本机 IPC。Unix socket 权限隔离用户，不隔离同一用户启动的其他本机程序。
