# ADR-006 黑框草稿空格与编辑

日期：2026-10-09，2026-10-10 完成代码回归。状态：实施。覆盖 ADR-005 中 Tab 立即提交当前词的行为。

Tab（可配置的空格动作）保存当前原始英文和一个空格到 Assistant 草稿；调用 marked text 更新显示，不调用 insertText 正式上屏。原始大小写保留。已有草稿时，Space 选入待选中文；没有待选拼音时 Space 确认原文。Option+Space 采用完整英文译文；纯英文草稿直接采用原文。普通未进入草稿的中文输入保持基础选词方式。

方向键进入草稿编辑，不提交到宿主。光标按 Unicode 字符计数，IMK 接口转换 UTF-16。前文文字编辑使用文字缓冲区；End 恢复末尾拼音输入。编辑会取消旧异步请求，重新请求当前完整源文。编辑后的候选学习元数据不再复用，防止改写文字污染拼音词频。

整句翻译快照使用当前高亮候选；逐词英文快捷路径只用于没有草稿且没有待采用译文的情况。显式预览期间 Enter 不转发给宿主。

选区替换需回读确认后产生现有 annotation 类型学习事件；无法回读时保守地不给学习计数。中英混输保留英文前后文，只提取被翻译的中文片段及英文结果，例如早餐/breakfast；模型改写英文前后文时不把整句误标为单词。

候选点击使用与绘制相同的列宽、行高、间距；竖排、横排、矩阵均可点击原文和句下译文。只有当前高亮源文拥有的译文可采用。

验证分为 Unicode 缓冲区单元测试、实际 NSEvent 分发加模拟 IMK 客户端、真实桥接检查、真实宿主人工验收。控制器模拟测试不宣称完成系统 IMK 激活及所有应用兼容性验收。
